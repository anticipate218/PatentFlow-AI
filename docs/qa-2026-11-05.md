# 2026 年 11 月 5 日功能验收记录

## 范围和结论

本轮以本地独立验收会话进行真实浏览器操作，并对现有公开站执行低流量 smoke 测试。浏览器实测、真实模型调用、模拟上游测试分别记录，不将自动化测试数量等同于所有按钮和所有输入均已通过。

参考材料、模型回复、导出的申请稿、截图和原始日志仅保存在被 Git 忽略的本地验收目录；本文件不包含密钥或参考论文内容。

主要流程实际通过：上传文字层 PDF、读取并回答、沿用附件指定主题、一键生成、下载八个 Word 分件与 ZIP、定点修改、重新下载、撤销、刷新后重新打开。

但不能据此宣称“任何参考文件均可读取”或“输出可未经审阅直接申报”。扫描 PDF 和纯图片 PPT 仍需要先提供可读取文字；图片只登记尺寸和参考说明，不进行视觉内容理解。本轮生成稿仍有检索和公式等人工核验事项。

## 本轮修复

1. **参考文件名抢占用户主题。** 新增“选择主题”“选定题目”等指令识别；参考材料存在时，明确指定的主题用于查新和撰写，而不是 PDF 文件名。不匹配当前主题的旧查新报告不再作为本轮查新结果复用。
2. **生成材料重复进入上下文。** 新生成的选题、大纲和查新报告带有来源标记；更新时只替换同名系统生成材料，不覆盖用户上传的同名文件。无法判定来源的历史材料不自动删除。
3. **知识库文件过滤器与读取能力不一致。** 与主输入区共用文件格式清单；补充读取中状态、成功数量和持续可见的失败说明，多文件上传不再只保留最后一条错误 toast。
4. **纯图片 PPT 被误认为已读取。** 只有页码而没有文字的幻灯片不再作为材料正文；混合 PPT 保留有文字页面的原始页码。
5. **窄屏预览横向溢出。** 案件面板改用可收缩的单列布局，长文本可换行。390 像素宽度下，原先约 852 像素宽的文档预览已缩回面板宽度内。
6. **侧栏与申请稿不同步。** 成稿后的权利要求、附图、审核、查新与修改记录直接读取当前申请稿。旧版案件字段为空时，不再错误显示“没有权利要求”“没有附图”或“没有问题”。附图面板显示与导出使用同一绘图数据生成的预览；卡片区分“正文待补充标记”和“待核验事项”，避免把零标记误解为没有待核验问题。

## 未覆盖与后续风险

复跑记录：一次本地 Worker 集成测试在发送超大请求时出现 ECONNRESET；不修改测试或放宽断言，再次完整执行后通过。该现象仍作为稳定性观察项保留，不能表述为其根因已被修复。

- 没有穷举全部按钮组合、所有行业、所有模型供应商和所有文件变种。
- 永久清空、删除已有用户资料、剪贴板中的未知内容导入，未在真实用户数据上执行；这里只验证确认/取消入口，相关状态逻辑仍由自动化测试覆盖。
- 其余快捷修改指令未逐个发起真实长文模型调用；本轮真实验证的是定点增加一句话、再次导出和撤销。
- 没有对每页正文逐字核验，也未进行专利新颖性、创造性或可实施性的专业审查。示例性参数限定仍需保留，不能转换为实测事实。
- 本轮长主题自动查新未获得可比对文献，而普通关键词查询能得到线索；长主题检索召回仍需继续改善，不能将零命中解释为创新已获确认。
- 附图中的语义关系和图表标注仍需人工核对；图形可渲染、标记齐全不代表技术关系必然正确。
- 未完成跨浏览器全矩阵、恶意压缩文件/超大文件压力测试、多用户负载测试以及长时间运行稳定性测试。
- 本地旧的第三方模型配置出现鉴权问题，不自动覆盖用户密钥。真实模型验收使用既有独立测试配置，不代表所有旧配置均有效。
