# 浏览量与访客统计

工作台顶部的统计按钮展示累计浏览（PV）与累计访客（UV），点击查看今日/累计四项数据。小屏幕使用图表按钮进入同一面板。

## 口径

- 确认免责声明后进入一个新页面文档计一次浏览；刷新或新开标签页再次进入会增加 PV。
- 站内切换、刷新统计面板和 48 小时内同一页面事件的重试不重复计数。浏览器直接恢复同一缓存页面不会作为新文档再计数。
- 打开统计面板会执行只读刷新；面板保持打开并跨越北京时间零点、或切回该标签页时也会刷新。旧快照明确显示其日期，不把昨天的数据标成“今日”。随机页面事件 ID 在匿名会话变化后仍保持幂等；历史累计数据不会为此被删除或重置。
- UV 以现有签名会话的去标识摘要去重；累计 UV 是不同匿名会话数，不是账号数或真实人数。会话过期、清除 Cookie、更换浏览器/设备会重新计数。默认会话有效期为 7 天。可选邀请模式下，同一邀请码共享标识，不能将其 UV 解释为独立用户数。
- 今日数据按北京时间零点分日；仅从功能启用时开始记录，没有虚构上线前的历史数据。验收访问可能被统计，数字不具备反作弊计费效力。
- DNT / GPC 隐私信号及可识别的搜索机器人不计数；禁用 JavaScript、未进入工作台或网络失败也可能少计。

## 存储与隔离

- 独立的 SQLite Durable Object：SITE_TRAFFIC / SiteTraffic，不共用模型配额计数，不调用模型或搜索服务。
- 统计数据只保留累计/日期计数、匿名会话摘要及短期随机页面事件 ID；不持久化上传内容、模型密钥、IP、访问 URL 或 Referer。摘要只用于去重，响应只返回聚合数据。
- 页面事件去重记录在后续写入时清理超过 48 小时的记录，日汇总类似清理 90 天以前的数据；累计数和会话摘要保留以支持累计去重。
- GET /api/traffic 只读；POST /api/traffic 仅接收随机 eventId，服务端验证当前公告会话后推导去重标识。不可由客户端指定访客身份，无公开重置接口。
- 统计写入为事务操作，重启/代码更新不清零；统计故障显示暂不可用，不阻塞生成和下载。统计接口有独立的每 IP 内存请求限速，不消耗共享模型/搜索配额。
- Vite 开发模式不累计公网数据；使用 npm run cf:dev 可验证独立的本地 Worker 数据。不要为这项功能同步或替换生产密钥。
